# PrivyGallery 2.3.1 更新日志

## 简体中文

修复 Live Photo 导入问题，包括从其他 App 分享导入。
Live Photo 导出回系统相册后可保留动态效果。
修复分享面板首次打开可能空白的问题，改善媒体与备份文件的分享体验。
改善解锁与密码设置体验，修复输错密码后的输入清空、键盘聚焦及小屏幕下解锁按钮显示问题。


## 繁體中文

修正 Live Photo 匯入問題，包括從其他 App 分享匯入。
Live Photo 匯出回系統「照片」後可保留動態效果。
修正分享面板首次開啟時可能空白的問題，改善媒體與備份檔案的分享體驗。
改善解鎖與密碼設定體驗，修正輸錯密碼後的輸入清除、鍵盤焦點及小螢幕上的解鎖按鈕顯示問題。


## English (U.S. / U.K.)

Fixed Live Photo importing, including imports shared from other apps.
Live Photos now retain their motion when saved back to Photos.
Fixed an issue where the share sheet could appear blank on first opening, and improved media and backup sharing.
Improved unlocking and password setup, fixing input clearing after incorrect passwords, keyboard focus, and unlock button visibility on smaller screens.


## 日本語

Live Photoの読み込みと、ほかのアプリから共有して読み込む際の問題を修正しました。
Live Photoを「写真」に保存する際に、動きが保持されるようになりました。
共有シートを初めて開いた際に空白になることがある問題を修正し、メディアとバックアップファイルの共有を改善しました。
ロック解除とパスワード設定を改善し、パスワードを間違えた後の入力クリア、キーボードのフォーカス、小さい画面でのロック解除ボタンの表示に関する問題を修正しました。
