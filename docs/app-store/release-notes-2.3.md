# PrivyGallery 2.3 更新日志

## 简体中文

加强密码验证、锁定与紧急抹除的安全保护，修复双空间切换密码类型时的更新问题。
改善备份恢复和从其他 App 分享导入的稳定性。
优化录屏时的内容遮挡与视频暂停，并修复恢复购买后的会员状态显示问题。

## 繁體中文（台灣）

加強密碼驗證、鎖定與緊急清除的安全保護，修正雙空間變更密碼類型時的更新問題。
改善備份復原及從其他 App 分享匯入的穩定性。
最佳化螢幕錄影時的內容遮蔽與影片暫停，並修正回復購買後的會員狀態顯示問題。

## 繁體中文（香港）

改善螢幕錄影時的內容遮蔽與影片暫停，並修正還原購買後的會員狀態顯示問題。
