# PrivyGallery 2.2 更新日志

## 简体中文

回收站支持批量恢复，归档支持批量放回。复制 Live Photo 时保留动态片段和原始文件名。
强保护视频现在分段读取，减少播放大文件时的内存占用。
改进备份恢复流程、相册滚动和 Mac 设置界面，并修复 Face ID 验证时锁定遮罩可能闪现的问题。
