## 用词说明

- 繁体按台湾用词（螢幕、影片、搜尋、介面、導覽）；香港商店需要「螢幕／影片／搜尋」但「App」照旧，可按需替换。
- 德、法、西、意用各平台的「你」称呼（du / vous / tú / tu），与 Apple 商店文案一致。
- 俄语用「вы」敬称形式。
- 新增内容每条一行、不带 `•`，与你现在后台里的排版一致。
